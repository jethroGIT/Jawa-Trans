1️⃣  getJumlahKursiReservasi(idReservasi)
    ├─ Input:  idReservasi (number)
    ├─ Output: Jumlah kursi (number)
    ├─ SQL:    SELECT COUNT(*) FROM reservasidetail WHERE idReservasi = ?
    └─ Usage:  const jmlh = await getJumlahKursiReservasi(1);

2️⃣  getTotalHargaReservasi(reservasi)
    ├─ Input:  reservasi object { idReservasi, hargaSatuan }
    ├─ Output: Total harga (number)
    ├─ Calc:   hargaSatuan * COUNT(reservasi_detail)
    └─ Usage:  const total = await getTotalHargaReservasi(res);
